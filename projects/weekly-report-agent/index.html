Run it in your own n8n

You will need: an n8n account, a Google Sheet of sales or bookings, an Anthropic API key, and Gmail.

  1. Download the workflow file below and choose Import from file in n8n.
  2. In Read the sheet, connect Google and paste your sheet link. Columns needed: Date, Product, Qty, Amount.
  3. In Claude writes it, add a Header Auth credential named x-api-key with your Anthropic API key.
  4. In Email you, connect Gmail and put your own address.
  5. Press Test workflow once, check the email, then switch the workflow to Active.

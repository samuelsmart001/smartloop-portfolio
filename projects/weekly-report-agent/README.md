# Weekly Report Agent

A SamuelSmart Automation project by Inioluwa Adebisi.

Every Monday at 8am, Claude reads last week's rows from a Google Sheet (columns: Date, Product, Qty, Amount), works out totals and changes, and emails a plain-English summary with three next steps.

Setup steps are on the project page: https://smartloop-portfolio.vercel.app/projects/weekly-report-agent/

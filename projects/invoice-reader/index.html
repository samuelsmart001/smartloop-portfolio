Invoice Reader

Supplier invoices arrive by email as PDFs. Claude reads each one, pulls out the vendor, amounts, due date and line items, and logs it in Google Sheets so nothing gets missed or typed twice.

Run it in your own n8n

You will need: an n8n account, Gmail, a Google Sheet, and an Anthropic API key.

  1. Download the workflow file below and choose Import from file in n8n.
  2. In New invoice email, connect Gmail. It watches for unread emails with a PDF and “invoice” in the subject.
  3. In Claude reads it, add a Header Auth credential named x-api-key with your Anthropic API key.
  4. In Log the invoice, connect Google and paste a sheet with a tab named Invoices.
  5. In Mark as done, choose a Gmail label such as “Invoice logged”, then test with one real invoice and switch the workflow to Active.

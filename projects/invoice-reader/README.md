# Invoice Reader

A SamuelSmart Automation project by Inioluwa Adebisi.

Watches Gmail for unread emails with a PDF and "invoice" in the subject, extracts the text, has Claude return clean JSON (vendor, number, dates, totals, line items), appends a row to the Invoices sheet, and labels the email.

Setup steps are on the project page: https://smartloop-portfolio.vercel.app/projects/invoice-reader/
